Embeddable heatmap widget

This page demonstrates the widget written alongside the full heatmap: $widget_filename. It is the same map without the control panel — still fully interactive (drag to pan, scroll or pinch to zoom) — shown here in a responsive frame that fills the width of whatever it is placed in.

Use it on your own page

Copy $widget_filename next to your page and drop this in. The wrapper keeps the iframe fluid, and the map inside frames itself to the data on load.

<div style="position:relative;width:100%;aspect-ratio:16/10">
  <iframe src="$widget_filename" title="Strava activity heatmap"
          loading="lazy"
          style="position:absolute;inset:0;width:100%;height:100%;border:0">
  </iframe>
</div>

Because the widget zooms on scroll, give it a fixed frame like this rather than a bare iframe whose height would depend on its content.
